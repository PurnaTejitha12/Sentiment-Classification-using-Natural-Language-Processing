# 🧠 AI Sentiment Analyzer

A simple and interactive web-based **Sentiment Analysis** application built using **HTML, CSS, and JavaScript**.

The application analyzes the text entered by the user and predicts whether the sentiment is:

- 😊 Positive
- 😞 Negative
- 😐 Neutral

## 📸 Features

- 🎨 Modern and attractive UI
- 📱 Responsive design for mobile and desktop
- 🧠 Sentiment prediction
- 😊 Positive sentiment detection
- 😞 Negative sentiment detection
- 😐 Neutral sentiment detection
- 📊 Sentiment score visualization
- ✍️ Character counter
- 💡 Example sentences for quick testing
- 🗑️ Clear button
- ✨ Animated background and UI elements
- ⚡ No backend required

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, animations, responsive design
- **JavaScript** – Sentiment analysis logic and interactivity
